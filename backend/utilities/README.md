# Utilities

This folder contains utility scripts for development and maintenance tasks.

## Scripts

### `insert_test_data.py`
Inserts sample test data (3 yarns and 2 projects) into the database for development and testing purposes.

**Usage:**
```bash
python backend/utilities/insert_test_data.py
```

## Notes

- These scripts are for development/maintenance use only
- Always backup your database before running utility scripts
- These scripts are not part of the main application code
