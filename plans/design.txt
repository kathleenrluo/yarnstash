🧶 Yarn & Project Tracker — Design Document
1. Purpose & Goals

This application is a local-first web app designed to:

Track yarn stash inventory

Track crochet/knit projects and yarn usage

Perform yarn usage calculations and estimates

Support future pattern creation tools

Be modular, API-driven, and deployable publicly later

Design principles

Logic lives in the backend (no business logic in React)

All state changes go through functions/APIs

Abstraction first: stash, projects, calculations, patterns are independent modules

Future extensibility: CV, ML, public APIs, mobile app

2. High-Level Architecture

3. Core Domains (Backend)
3.1 Yarn Domain

Yarn is information, not inventory.

Yarn Model
Yarn
- id
- brand_name
- yarn_name
- color_name
- generalized_color
- yarn_weight (e.g. DK, Worsted)
- material_breakdown (structured percentages)
- grams_per_skein
- meters_per_skein
- care_instructions
- yarn_photo_url
- label_photo_url
- created_at


💡 Even if stash quantity is 0, Yarn persists.

3.2 Stash Domain

Inventory is separate from yarn metadata.

StashEntry
StashEntry
- id
- yarn_id
- total_grams_owned
- last_updated

Invariants

Stash can only be updated via:

use_yarn()

add_yarn_by_grams()

add_yarn_by_skeins()

No direct mutation allowed elsewhere

This is critical for correctness.

3.3 Project Domain
Project
Project

- pattern_type (pdf | link | freehand)
- pattern_reference

ProjectYarnUsage (join table)
ProjectYarnUsage
- project_id

- grams_used

3.4 Care Instruction Logic

Each yarn has care instructions.

A resolver function computes the most restrictive one:

hand wash cold > gentle machine > machine wash
dry flat > tumble dry low > tumble dry


This function:

Takes a list of yarns

Returns a single garment-safe instruction

Is reusable across projects & patterns

4. Calculation Engine

This is a pure Python module — no DB access.

Responsibilities

Estimate meters used per stitch

Convert meters → grams (per yarn)

Aggregate project yarn requirements

Core Concepts
Stitch Usage Rule
(stitch_type, yarn_weight, hook_size)
→ meters_per_stitch


Stored as:

Config table OR

Versioned JSON file

Replaceable later with ML model

Estimation Flow
Pattern definition
→ total stitches
→ total meters
→ per-yarn grams required
→ stash sufficiency check


This engine must be:

Deterministic

Testable

Independent of UI
